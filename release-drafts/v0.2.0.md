Setup wizard. Verified on a clean machine from zero.

- Steps: check → venv → engine → license → weights → smoke. Each step checks the disk first; re-running is safe.
- Downloads resume from `.part` files; finished shards are not re-downloaded.
- Long steps run as background jobs. Progress is read from disk state, not exit codes. After an app restart a job reports `interrupted`, never "done".
- License must be accepted by you.
- Requires Apple Silicon. 48 GB+ recommended; 32 GB works with risk confirmation.
